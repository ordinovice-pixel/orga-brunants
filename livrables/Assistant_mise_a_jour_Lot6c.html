Quand les 10 fichiers sont remplacés

  1. Cliquez sur 💾 Enregistrer le projet : plus aucun point orange à côté des noms.
  2. Exécutez setup :
    • cliquez sur Code.gs dans la liste des fichiers (le bouton « Exécuter » n'apparaît que sur un fichier .gs) ;
    • dans la liste déroulante à côté de « Débogage », choisissez setup — ni doGet, ni menuSetup ;
    • cliquez sur ▷ Exécuter et attendez « Installation terminée » dans le journal d'exécution (30 secondes à 1 minute).
    Il charge les nouvelles données d'entraînement dans les onglets encore vides, sans toucher au reste.
    Dans le journal, vous devez voir : « Paramètres : nombre de sauvegardes conservées passé de 12 à 24 », « Catégories : sous-catégorie « 8.3 Dons » ajoutée » et « Catégories : descriptif de 7.2 mis à jour ». Aucune nouvelle autorisation n'est demandée.
  3. Publiez la nouvelle version du déploiement existant : Déployer → Gérer les déploiements → sélectionnez le déploiement actif → icône ✏️ (modifier) → Version : Nouvelle version → Déployer.
    ⚠️ N'utilisez pas « Nouveau déploiement » : cela créerait une deuxième adresse. L'adresse de l'outil ne doit jamais changer.
  4. Rechargez l'outil dans le navigateur (F5) : le bas de la barre latérale doit afficher « Lot 6c ».
  5. Suivez ensuite, dans LISEZMOI_Lot6c.md, la partie « Importer vos vrais adhérents ». Ne lancez pas l'import avant d'avoir installé cette mise à jour : c'est elle qui protège vos adhérents réels.
