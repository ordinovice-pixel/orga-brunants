# Captures d'écran de l'outil et du guide

Prises le 02/11/2026 dans l'**aperçu local** (`livrables/Apercu_local_Brunants.html`), qui fait tourner le vrai code de l'outil (version lot 6c) sans Google. Les données sont celles du **jeu d'entraînement** : adhérents, activités, montants et prestataires sont fictifs, et les noms de famille des adhérents ont été remplacés par des noms inventés (plantes, oiseaux…). Aucune donnée réelle n'apparaît.
